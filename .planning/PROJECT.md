# 이유식 다이어리 (가칭)

## What This Is

부부가 각자 계정으로 로그인해서 같은 아기의 이유식 식단을 함께 짜고, 먹인 결과를 기록·공유하는 모바일 중심 웹앱(PWA). 종이 이유식 달력(Mamma Calendar)처럼 **먼슬리 달력이 홈 화면**이고, 위클리 화면에서 끼니별 식단과 기록을 관리한다. 화면은 실제 다이어리에 펜으로 쓴 것 같은 아날로그 플래너 감성으로 만들고, 한 달 식단표를 "마스킹테이프로 붙인 종이 달력 사진"처럼 이미지로 내보낼 수 있다.

## Core Value

부부가 같은 이유식 계획과 기록을 실시간으로 보면서, **새 재료를 안전한 간격으로 하나씩 테스트하고 그 반응을 놓치지 않는 것.**

### Active

**계정·공유**
- [ ] 부부가 각자 계정으로 로그인하고, 같은 아기(가정)의 데이터를 함께 본다
- [ ] 한 사람이 바꾼 식단·기록이 다른 사람 화면에 실시간(또는 준실시간)으로 반영된다
- [ ] 아기 정보(이름, 생년월일)를 등록하면 날짜마다 D+일수가 계산된다

**먼슬리 (홈)**
- [ ] 홈 화면은 월간 달력이고, 각 칸에는 날짜·D+일수·그날의 새 재료 등 요약만 보인다
- [ ] 새 재료 테스트 기간이 날짜 칸을 가로지르는 색 띠(마스킹테이프 느낌)로 이어져 표시된다
- [ ] 상단에 현재 단계(초기/중기/후기), 이달의 주의 식재료, 이달의 목표를 표시하고 편집할 수 있다
- [ ] 날짜를 누르면 해당 날짜/주의 상세로 이동한다

**위클리 (상세 계획 + 기록)**
- [ ] 요일 탭별로 끼니(1끼니 이상, 늘릴 수 있음) 식단을 짠다 — 끼니마다 재료와 양(g)
- [ ] 같은 화면에서 먹인 결과를 기록한다: 먹은 양, 반응·알레르기(이상 증상 + 메모), 좋아함/거부, 사진
- [ ] 주간 메모와 주간 체크리스트(예: 큐브 만들기, 장보기)가 있다

**새 재료 규칙**
- [ ] 식단을 직접 짜면, 새 재료 테스트 간격(기본 3일, 설정에서 변경 가능)을 어기거나 같은 기간에 새 재료가 겹칠 때 경고한다 (자동 추천은 하지 않음)

**재료 목록**
- [ ] 먹어본 재료 목록에서 재료별 처음 먹인 날, 반응 여부, 상태(통과/주의/테스트 중)를 한눈에 본다

**큐브·재고**
- [ ] 재료별 냉동 큐브 재고를 관리한다
- [ ] 먹인 기록을 남기면 사용한 큐브 수만큼 재고가 자동으로 줄어든다
- [ ] 앞으로 짜둔 식단 대비 큐브가 부족하면 표시한다

**장볼 목록**
- [ ] 식단과 재고를 바탕으로 필요한 재료를 장볼 목록으로 모아 보고 체크한다

**알림 (푸시)**
- [ ] 큐브가 부족해지면 알림을 보낸다
- [ ] 전날에 "내일 처음 먹이는 재료"를 알림으로 보낸다

**이미지 내보내기**
- [ ] 한 달 식단표를 이미지로 내보낸다 — 단순한 배경지 위에 마스킹테이프로 붙인 종이 달력 실사 느낌
- [ ] 내보낸 이미지의 날짜 칸에는 재료와 그램 수(예: 쌀 20g / 소고기 10g)가 모두 들어가고, 손글씨 폰트·색 띠·상단 정보(단계, 주의 식재료, 목표)가 함께 나온다

**디자인**
- [ ] 크림·베이지 바탕과 로즈베이지 포인트를 쓰는 아날로그 플래너 무드 (참고/컨셉2.png)
- [ ] 제목(Monthly, Weekly 등)은 세리프체, 날짜 칸·기록 같은 내용은 펜글씨 폰트로 실제 다이어리에 쓴 것처럼 보이게 한다
- [ ] 휴대폰 화면 기준으로 설계하고 홈 화면에 추가(PWA)할 수 있다

### Out of Scope

- 식단 자동 추천/자동 생성 — 사용자가 직접 짜고, 앱은 규칙 위반 경고만 한다
- 작성자(엄마/아빠) 표시 — 각자 계정이지만 누가 기록했는지는 굳이 보여주지 않아도 됨
- 수유·수면·기저귀 등 다른 육아 기록 — 기존 육아앱이 "기능이 너무 많아서" 불편했음. 이유식에만 집중
- 이유식 시간 알림, 배우자 기록 알림 — 이번에 필요한 알림은 큐브 부족·내일 새 재료 두 가지뿐
- 네이티브 앱(앱스토어 배포) — 부부 둘만 쓰는 앱이라 PWA로 충분
- 오프라인 우선 동기화 — 연결된 상태에서의 실시간 공유면 충분

## Context

- 아기는 현재 **초기 이유식(미음)** 단계: 새 재료를 하나씩 추가하며 며칠씩 반응을 확인하는 시기. 앞으로 중기·후기로 가면 끼니 수와 재료 조합이 늘어남.
- 지금은 다른 육아앱을 쓰고 있는데 불편한 점: 식단을 미리 짜기 어려움, 부부 공유가 아쉬움, 재료·알레르기 추적이 안 됨, 이유식 외 기능이 너무 많음.
- 디자인 참고 이미지:
  - `참고/컨셉.png` — 실물 "Mamma Calendar" 이유식 달력. 먼슬리 구조, 칸마다 날짜+D+일수, 재료+g 손글씨, 주마다 마스킹테이프 색 띠, 채소 스티커, 상단 단계 체크(초기/중기/후기)·주의 식재료·이달의 목표. **먼슬리 레이아웃과 이미지 내보내기 결과물의 기준.**
  - `참고/컨셉2.png` — 크림/베이지 톤 미니멀 플래너(Monthly / Weekly / Habit Tracker). 세리프 제목, 로즈베이지 포인트, 위클리는 요일 탭이 세로로 이어지고 Memo·Checklist 패널. **색감·타이포·위클리 레이아웃의 기준.**
- 주 사용 환경: 휴대폰(홈 화면 추가). PC 사용은 고려하지 않음.

## Constraints

- **Platform**: 모바일 웹 PWA — 홈 화면 추가와 푸시 알림(iOS는 16.4+, 홈 화면 추가 필요) 때문
- **Users**: 한 가정(부부 2명) + 아기 1명 — 다만 데이터 모델은 여러 아기를 받을 수 있게 두어 나중에 재작업을 피함
- **Sync**: 부부가 동시에 봐도 최신 식단·기록이 반영되어야 함
- **Design fidelity**: 펜글씨 한글 폰트와 실사 느낌 내보내기가 핵심 경험 — 기본 UI 키트처럼 보이면 실패
- **Budget**: 무료 티어 내에서 운영
