# Requirements: 이유식 다이어리 (가칭)

**Defined:** 2026-10-06
**Core Value:** 부부가 같은 이유식 계획과 기록을 실시간으로 보면서, 새 재료를 안전한 간격으로 하나씩 테스트하고 그 반응을 놓치지 않는 것.

## v1 Requirements

### 계정·공유 (ACCT)

- [ ] **ACCT-01**: 사용자는 이메일/비밀번호로 각자 계정을 만들고 로그인할 수 있다
- [ ] **ACCT-02**: 사용자는 앱을 닫았다 열어도(홈 화면 PWA 포함) 로그인 상태가 유지된다
- [ ] **ACCT-03**: 사용자는 배우자를 같은 가정에 초대(또는 참여)해서 같은 아기 데이터를 함께 볼 수 있다
- [ ] **ACCT-04**: 사용자는 아기 이름과 생년월일을 등록·수정할 수 있다
- [ ] **ACCT-05**: 한 사람이 바꾼 식단·기록이 다른 사람 화면에 새로고침 없이 수 초 안에 반영된다

### 먼슬리 (MON)

- [ ] **MON-01**: 앱을 열면 이번 달 월간 달력이 홈 화면으로 보인다
- [ ] **MON-02**: 사용자는 이전/다음 달로 이동할 수 있다
- [ ] **MON-03**: 각 날짜 칸에 날짜와 D+일수(생년월일 기준)가 보인다
- [ ] **MON-04**: 각 날짜 칸에 그날의 식단 요약(새 재료 표시 포함)이 보인다
- [ ] **MON-05**: 새 재료 테스트 기간이 날짜 칸을 가로지르는 색 띠(마스킹테이프 느낌)로 이어져 보이고, 주가 바뀌면 다음 줄로 이어진다
- [ ] **MON-06**: 사용자는 달 상단에서 현재 단계(초기/중기/후기)를 표시·변경할 수 있다
- [ ] **MON-07**: 사용자는 달마다 '주의 식재료'와 '이달의 목표'를 적고 고칠 수 있다
- [ ] **MON-08**: 사용자는 날짜를 눌러 그 날짜가 포함된 위클리 화면으로 이동할 수 있다

### 위클리 (WEEK)

- [ ] **WEEK-01**: 사용자는 요일 탭으로 한 주를 보고 이전/다음 주로 이동할 수 있다
- [ ] **WEEK-02**: 사용자는 날짜마다 끼니를 추가·삭제할 수 있다 (초기엔 1끼니, 나중에 늘림)
- [ ] **WEEK-03**: 사용자는 끼니마다 재료와 양(g)을 입력해서 식단을 짤 수 있다 (예: 쌀 20g, 소고기 10g)
- [ ] **WEEK-04**: 사용자는 재료를 '새 재료(테스트 시작)'로 표시할 수 있다
- [ ] **WEEK-05**: 사용자는 주간 메모를 적을 수 있다
- [ ] **WEEK-06**: 사용자는 주간 체크리스트 항목(예: 큐브 만들기, 장보기)을 추가하고 체크할 수 있다

### 먹인 기록 (LOG)

- [ ] **LOG-01**: 사용자는 끼니마다 실제로 먹은 양을 기록할 수 있다
- [ ] **LOG-02**: 사용자는 끼니마다 반응(이상 없음 / 이상 증상 + 메모)을 기록할 수 있다
- [ ] **LOG-03**: 사용자는 끼니마다 좋아함/보통/거부를 표시할 수 있다
- [ ] **LOG-04**: 사용자는 끼니마다 사진을 올리고 볼 수 있다
- [ ] **LOG-05**: 기록된 끼니는 계획만 있는 끼니와 화면에서 구분된다

### 새 재료 규칙 (RULE)

- [ ] **RULE-01**: 앱은 처음 쓰는 재료를 이전 기록·식단을 바탕으로 '새 재료'로 알아본다
- [ ] **RULE-02**: 새 재료 테스트 기간 안에 다른 새 재료를 넣으면 경고가 보인다
- [ ] **RULE-03**: 테스트 간격은 기본 3일이고, 사용자가 설정에서 바꿀 수 있다
- [ ] **RULE-04**: 경고는 막지 않고 알려주기만 한다 (사용자가 무시하고 저장할 수 있음)
- [ ] **RULE-05**: 이상 반응을 기록한 재료는 이후 식단에 넣을 때 주의 표시가 보인다

### 이미지 내보내기 (EXP)

- [ ] **EXP-01**: 사용자는 한 달 식단표를 이미지 파일로 저장(또는 공유)할 수 있다
- [ ] **EXP-02**: 내보낸 이미지는 단순한 배경지 위에 종이 달력이 마스킹테이프로 붙어 있는 실사 느낌이다
- [ ] **EXP-03**: 내보낸 이미지의 날짜 칸에는 날짜, D+일수, 재료와 그램 수가 모두 손글씨 폰트로 들어간다 (끼니가 여러 개면 ①② 구분)
- [ ] **EXP-04**: 내보낸 이미지에 새 재료 색 띠와 상단 정보(단계, 주의 식재료, 이달의 목표)가 함께 나온다

### 디자인·PWA (UI)

- [ ] **UI-01**: 크림·베이지 바탕과 로즈베이지 포인트를 쓰는 아날로그 플래너 무드로 화면이 구성된다 (참고/컨셉2.png)
- [ ] **UI-02**: 제목(Monthly, Weekly 등)은 세리프체, 날짜 칸·식단·기록 같은 내용은 한글 펜글씨 폰트로 보인다
- [ ] **UI-03**: 모든 화면이 휴대폰 세로 화면에서 가로 스크롤 없이 쓸 수 있다
- [ ] **UI-04**: 사용자는 앱을 홈 화면에 추가해서 앱처럼 실행할 수 있다 (PWA)

## v2 Requirements

### 재료 목록 (ING)

- **ING-01**: 사용자는 먹어본 재료 목록에서 재료별 처음 먹인 날, 반응 여부, 상태(통과/주의/테스트 중)를 본다

### 큐브·재고 (CUBE)

- **CUBE-01**: 사용자는 재료별 냉동 큐브 재고를 관리한다
- **CUBE-02**: 먹인 기록을 남기면 사용한 큐브 수만큼 재고가 자동으로 줄어든다
- **CUBE-03**: 짜둔 식단 대비 큐브가 부족하면 표시된다

### 장볼 목록 (SHOP)

- **SHOP-01**: 사용자는 식단·재고를 바탕으로 모인 장볼 목록을 보고 체크한다

### 알림 (NOTI)

- **NOTI-01**: 큐브가 부족해지면 푸시 알림을 받는다
- **NOTI-02**: 전날에 "내일 처음 먹이는 재료" 푸시 알림을 받는다

## Out of Scope

| Feature | Reason |
|---------|--------|
| 식단 자동 추천/자동 생성 | 사용자가 직접 짜고, 앱은 규칙 위반 경고만 한다 |
| 작성자(엄마/아빠) 표시 | 각자 계정이지만 누가 기록했는지는 필요 없음 |
| 수유·수면·기저귀 등 다른 육아 기록 | 기존 육아앱이 기능이 너무 많아 불편했음 — 이유식에만 집중 |
| 이유식 시간 알림, 배우자 기록 알림 | 필요한 알림은 큐브 부족·내일 새 재료뿐 |
| PC 최적화 레이아웃 | 휴대폰 위주로 사용 |
| 네이티브 앱(앱스토어) | 부부 둘만 쓰는 앱이라 PWA로 충분 |
| 오프라인 우선 동기화 | 연결된 상태에서의 실시간 공유면 충분 |
