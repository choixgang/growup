# Roadmap: 이유식 다이어리 (가칭)

## Overview

부부가 함께 쓰는 이유식 다이어리 PWA를 4단계로 완성한다. 1단계는 부부 공용 가정 계정과 아기 정보, 아날로그 플래너 감성의 디자인 시스템(세리프/펜글씨 폰트, 크림·베이지+로즈베이지 톤), PWA 쉘, 그리고 D+일수가 보이는 먼슬리 홈 화면 틀을 세운다. 2단계는 위클리 화면에서 끼니별 식단을 짜고 먹인 결과(양·반응·호불호·사진)를 기록하며, 부부 간 실시간 동기화를 완성해 "누가 언제 뭘 했는지 헷갈리지 않는다"는 핵심 가치를 처음으로 끝까지 전달한다. 3단계는 새 재료 테스트 간격 위반 경고 규칙과 먼슬리 홈의 색 띠·식단 요약·상단 정보(단계/주의 식재료/이달의 목표)를 더해 종이 달력 수준의 정보 밀도를 재현한다. 4단계는 한 달 식단표를 마스킹테이프로 붙인 종이 달력 실사 이미지로 내보내 외부에 저장·공유할 수 있게 마무리한다.

- [ ] **Phase 2: 위클리 계획 & 먹인 기록** - 위클리 화면에서 식단을 짜고 먹인 결과를 기록하며, 부부 간 실시간 동기화를 완성한다
- [ ] **Phase 3: 새 재료 규칙 & 먼슬리 요약** - 새 재료 테스트 간격 경고와 먼슬리 홈의 색 띠·요약·상단 정보를 더한다

## Phase Details

### Phase 1: 기초 — 계정·가정 공유 & 플래너 디자인 시스템
**Goal**: 부부가 각자 계정으로 로그인해서 같은 가정(아기)의 데이터를 보고, 아날로그 플래너 감성의 디자인 시스템과 PWA 쉘 위에서 D+일수가 보이는 먼슬리 홈 화면이 뜬다
**Mode**: mvp
**Depends on**: Nothing (first phase)
**Requirements**: ACCT-01, ACCT-02, ACCT-03, ACCT-04, MON-01, MON-02, MON-03, UI-01, UI-02, UI-03, UI-04
**Success Criteria** (what must be TRUE):
  1. 사용자는 이메일/비밀번호로 각자 계정을 만들어 로그인하고, 앱을 껐다 켜도(홈 화면 PWA 포함) 로그인이 유지된다
  2. 사용자는 배우자를 같은 가정에 초대해 둘 다 같은 아기 데이터를 함께 본다
  3. 사용자는 아기 이름과 생년월일을 등록·수정할 수 있다
  4. 앱을 열면 이번 달 월간 달력이 홈 화면으로 보이고, 각 날짜 칸에 날짜와 D+일수(생년월일 기준)가 보이며, 이전/다음 달로 이동할 수 있다
  5. 전체 화면이 크림·베이지 바탕과 로즈베이지 포인트의 아날로그 플래너 무드(세리프 제목 + 한글 펜글씨 폰트)로 보이고, 세로 화면에서 가로 스크롤 없이 쓸 수 있으며, 홈 화면에 추가해 PWA로 실행할 수 있다

### Phase 2: 위클리 계획 & 먹인 기록
**Goal**: 부부가 위클리 화면에서 끼니별 식단을 짜고 먹인 결과를 기록하면, 상대방 화면에도 새로고침 없이 수 초 안에 반영된다
**Mode**: mvp
**Depends on**: Phase 1
**Requirements**: ACCT-05, MON-08, WEEK-01, WEEK-02, WEEK-03, WEEK-04, WEEK-05, WEEK-06, LOG-01, LOG-02, LOG-03, LOG-04, LOG-05
**Success Criteria** (what must be TRUE):
  1. 사용자는 먼슬리에서 날짜를 눌러 해당 위클리로 이동하고, 요일 탭으로 한 주를 보며 이전/다음 주로 이동할 수 있다
  2. 사용자는 날짜마다 끼니를 추가·삭제하고, 끼니마다 재료와 양(g)을 입력해 식단을 짜며, 재료를 '새 재료(테스트 시작)'로 표시할 수 있다
  3. 사용자는 주간 메모를 적고, 주간 체크리스트 항목(예: 큐브 만들기, 장보기)을 추가·체크할 수 있다
  4. 사용자는 끼니마다 먹은 양, 반응(이상 없음/이상 증상+메모), 좋아함/보통/거부, 사진을 기록할 수 있고, 기록된 끼니는 계획만 있는 끼니와 화면에서 구분된다
  5. 한 사람이 바꾼 식단이나 기록이 배우자 화면에 새로고침 없이 수 초 안에 반영된다

### Phase 3: 새 재료 규칙 & 먼슬리 요약
**Goal**: 식단을 짤 때 새 재료 테스트 간격 위반을 경고받고, 먼슬리 홈에서 새 재료 테스트 기간과 이달 정보를 한눈에 본다
**Mode**: mvp
**Depends on**: Phase 2
**Requirements**: MON-04, MON-05, MON-06, MON-07, RULE-01, RULE-02, RULE-03, RULE-04, RULE-05
**Success Criteria** (what must be TRUE):
  1. 식단에 처음 쓰는 재료를 넣으면 앱이 이전 기록·식단을 바탕으로 자동으로 '새 재료'로 알아본다
  2. 새 재료 테스트 기간(기본 3일, 설정에서 변경 가능) 안에 다른 새 재료를 넣으면 경고가 보이지만, 저장을 막지는 않는다
  3. 이상 반응을 기록한 재료를 이후 식단에 다시 넣으면 주의 표시가 보인다
  4. 먼슬리의 각 날짜 칸에 그날 식단 요약(새 재료 표시 포함)이 보이고, 새 재료 테스트 기간이 날짜 칸을 가로지르는 색 띠로 이어져 보이며 주가 바뀌면 다음 줄로 이어진다
  5. 사용자는 먼슬리 상단에서 현재 단계(초기/중기/후기), 이달의 주의 식재료, 이달의 목표를 표시·수정할 수 있다

### Phase 4: 이미지 내보내기
**Goal**: 한 달 식단표를 마스킹테이프로 붙인 종이 달력 실사 느낌의 이미지로 내보내 저장·공유할 수 있다
**Mode**: mvp
**Depends on**: Phase 3
**Requirements**: EXP-01, EXP-02, EXP-03, EXP-04
**Success Criteria** (what must be TRUE):
  1. 사용자는 한 달 식단표를 이미지 파일로 저장하거나 공유할 수 있다
  2. 내보낸 이미지는 단순한 배경지 위에 종이 달력이 마스킹테이프로 붙어 있는 실사 느낌을 낸다
  3. 내보낸 이미지의 각 날짜 칸에는 날짜, D+일수, 재료와 그램 수가 손글씨 폰트로 모두 들어가고, 끼니가 여러 개면 ①②로 구분된다
  4. 내보낸 이미지에 새 재료 색 띠와 상단 정보(단계, 주의 식재료, 이달의 목표)가 함께 나온다
