# 이유식 다이어리

부부가 함께 쓰는 이유식 식단표 PWA. 먼슬리 달력이 홈이고, 위클리에서 끼니별 식단과 먹인 기록을 남깁니다. 한 달 식단표를 마스킹테이프로 붙인 종이 달력처럼 이미지로 내보낼 수 있어요.

## 바로 실행 (로컬 모드)

```bash
npm install
npm run dev
```

`.env` 없이 실행하면 **로컬 모드**로 동작합니다. 로그인 없이 바로 쓸 수 있지만 이 기기(브라우저)에만 저장돼서 배우자와 공유되지 않아요.

## 부부 공유 설정 (Supabase)

1. [supabase.com](https://supabase.com)에서 무료 프로젝트를 만듭니다.
2. 대시보드 **SQL Editor**에 `supabase/schema.sql` 내용을 붙여넣고 실행합니다. (테이블, 권한, 실시간, 사진 저장소가 한 번에 만들어져요)
3. **Project Settings → API**에서 URL과 `anon` 키를 복사해 `.env`를 만듭니다.
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJ...
   ```
4. (선택) 가입 확인 메일 없이 바로 쓰려면 **Authentication → Providers → Email**에서 *Confirm email*을 끕니다.
5. 한 사람이 가입 → 아기 등록 → **Settings**의 6자리 초대 코드를 배우자에게 알려줍니다. 배우자는 가입 후 *초대 코드로 참여*에 입력하면 같은 다이어리를 실시간으로 함께 봅니다.

## 배포

Vercel 등 정적 호스팅에 올리면 됩니다 (`vercel.json`에 SPA 경로 설정 포함). 환경 변수 두 개를 호스팅 설정에 넣어주세요. 휴대폰에서 연 뒤 **홈 화면에 추가**하면 앱처럼 실행돼요.

## 기능

- **Monthly**: 날짜·D+일수·새 재료 요약, 새 재료 테스트 기간 마스킹테이프 띠, 단계(초기/중기/후기)·주의 식재료·이달의 목표
- **Weekly**: 요일 탭별 끼니 식단(재료+g), 먹인 양·반응·좋아함/거부·사진 기록, 주간 메모·체크리스트
- **새 재료 규칙**: 처음 쓰는 재료를 자동으로 새 재료로 인식, 테스트 기간(기본 3일, 설정 변경) 중 다른 새 재료를 넣으면 경고(저장은 가능), 이상 반응 재료 주의 표시
- **이미지 내보내기**: 벽/린넨/우드 배경 위 종이 달력 실사 느낌 JPEG, 칸마다 재료+g 손글씨

## 개발

```bash
npm test        # 새 재료 규칙 단위 테스트
npm run build   # 타입 체크 + 프로덕션 빌드
```

구조: `src/lib/rules.ts`(새 재료 규칙), `src/data/`(Supabase/로컬 저장소 — 같은 `Repo` 인터페이스), `src/components/MonthGrid.tsx`(앱·내보내기 공용 달력), `src/pages/`(화면).
